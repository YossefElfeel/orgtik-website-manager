# @orgtik/ui 1.0.0-rc.1

Released 2026-09-30, as a local tarball. Publishing to sdk.orgtik.org waits for publish rights (PM packet).

- **File:** `orgtik-ui-1.0.0-rc.1.tgz`
- **SHA-256:** `3b7e507d520b85662b5dcc17e997be7e1ca2ba70f67e732bdfccd9079d66b359`

## Install

```bash
npm i ../orgtik-ui/releases/orgtik-ui-1.0.0-rc.1.tgz @phosphor-icons/react
```

Optional peers:
- `react-hook-form`, for `@orgtik/ui/rhf`
- `@tanstack/react-table`, for `@orgtik/ui/table`

Setup is in `packages/ui/README.md`: one CSS line, then the root layout.

## What's in it: the P1a scope (D-030)

- **Tokens v0 (D-024):**
  - light (the default, D-023) and dark
  - `:lang(ar)` type
  - reduced motion
  - derived hover, pressed and brand-subtle colours that also recompute inside a scoped `[data-theme]`
  - elevation and scrim
  - `font-mono`
- **Fonts:** IBM Plex Sans Arabic for Arabic characters only (D-010), and Montserrat latin + latin-ext. Both are OFL-1.1, and their licences are in `fonts/`.
- **Language:** 5 languages with RTL, library strings in all five, Arabic plurals, and Latin/Arabic digits per person (D-016).
- **Components:**
  - Button (including the brand pill), IconButton
  - Field, Input, PasswordInput, Checkbox, Switch, Select
  - Dialog, Sheet, ConfirmDialog, Menu, Popover, Tooltip
  - Badge, StatusBadge (the unified status matrix, labels per viewer), Avatar, Card, Skeleton, Spinner, Toast
  - Tabs, Pagination, Breadcrumb, PageHeader
  - EmptyState, ErrorState, NoPermissionState, LoadingState, ListStates
- **Separate entries:**
  - `@orgtik/ui/table`: DataTable
  - `@orgtik/ui/rhf`: react-hook-form adapters
  - `@orgtik/ui/next`: OrgtikNextProvider
- **Shell:** SuiteShell, AppRail, Sidebar, TopBar, UserMenu, BannerRegion (D-026 priority, and the staff ribbon), Logo.

## Proof

- **Storybook gate** (`apps/docs`): 23 stories × 6 theme/language combinations = 138 renders. All match their baselines, with 0 axe critical/serious, 0 console errors and 0 page overflow.
- **Smoke apps:** Next 16.3 + Tailwind 4.3, and Next 15.5 + Tailwind 4.1, render the same.
- **VS-1 in the real apps** (`wave1/vs-1` branches):
  - SOS sign-in and Files' My files: 20 of 20 clean each (5 languages × 2 themes × 390/1440).
  - The journey sign-in → launcher → shell → Files list passes in English and Arabic.
