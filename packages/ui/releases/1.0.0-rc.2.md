## New since rc.1: P1b is complete

- **Text:** Textarea (inside a Field it is labelled; it grows with its text).
- **Choice:**
  - RadioGroup.
  - SegmentedControl, which always has one choice and reports aria-pressed.
  - Combobox.
  - MultiSelect, with removable chips.
- **Numbers:** NumberField (the person's digits, LTR inside RTL), MoneyField (the currency's minor units: CHF 2, KWD 3), PercentField.
- **Languages:** LocalizedField: a tab per language with its state, opening on the first error (D-014, still awaiting the PM).
- **Limits:** Progress, Meter, LimitMeter with the spec's OK / near / full / over states, spoken and not only coloured.
- **Filters and files:** Tag, FilterChips, FileField (refused files are named, with the reason).
- **Disclosure:** Accordion, Collapsible, ScrollArea, Separator.
- **Dates:** the `@orgtik/ui/dates` entry, with Calendar, RangeCalendar, DatePicker and DateRangePicker. They use React Aria in a Base UI popover and take ISO dates. Arabic uses the Gregorian calendar with the person's digits.

## Fixes found by using it in the real apps (VS-1)

- **DataTable:**
  - A truncating column keeps at least 12rem.
  - Absolutely placed content stays clipped in the scroller. It had widened Arabic pages by 42px.
- **Sidebar:** labels are `dir="auto"`, so user content keeps its own direction.
- **Avatar:** xs shows one initial, because in stacks the second letter hid under the next circle.
- **Themes:** derived tokens recompute inside a scoped `[data-theme]`, and the staff ribbon sits on dark chrome in both themes.
